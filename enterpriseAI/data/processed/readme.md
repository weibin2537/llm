# 说明

存数据处理分析过程的



为什么neo4j的数据源选择通过python处理的json文件，而不是直接处理bdy文件？ 因为 json文件可以被neo4j和模型训练一起使用，解析一次，可被双方都使用，所以选择的是这个



因为要展示存储过程的影响分析,所以做了一个解析bdy的,然后将其以图的形式存储, 然后将 其转化为json文件, 如下格式,这样 即便没有智能助手,前端也能以图的形式展示

```json
{
    "PROC_LOGIN": ["PROC_AUTH", "PROC_LOGGER"],
    "PROC_AUTH": ["PROC_DB_VALIDATE"],
    "PROC_LOGGER": [],
    "PROC_DB_VALIDATE": []
  }
  
```



齐次就是:这里代码的逻辑主要是:通过loadxxx.py来处理不同数据,然后构造sft,在过程中不断构建提示词,然后存入到sft, 生成对应的jsonl文件, 而这些文件会作为语料被模型训练所加载学习,  然后模型会输出对应的权重模型, 之后模型自我学习和纠正
